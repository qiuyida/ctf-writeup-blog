## 视觉验收要点（截图目检）

- 黑洞阴影深黑、边缘锐利；光子环为连续细亮环，内缘蓝白。
- 吸积盘呈上部/下部透镜高阶像，多次穿越分层清晰；Doppler 增亮使接近侧显著更亮且偏蓝，远离侧偏橙。
- 盘面湍流旋臂结构随时间演化（Kepler 共转噪声域）；径向温度梯度（内白外橙）成立。
- 程序化星空与银河带经引力透镜弯折；恒星星点经 3×3×3 邻域采样，无裁剪伪影。
- Bloom 收敛于高温区域，无大面积雾状过曝；ACES 下暗部保留细节；暗角/颗粒/轻色散为电影感服务。

## 迭代修复记录（开发中发现并解决）

1. 星空哈希单格裁剪 → 星点呈虚线：改 3×3×3 邻域采样。
2. 步数耗尽的未逃逸光线误采星空 → 阴影内漏星点：仅明确逃逸者采天光，minR>3 者以暗淡天光填充高阶像接缝。
3. 盘面黑体近似各温等亮 → 全盘白化：加入玻尔兹曼辐射权重，形成内白外橙梯度。
4. 逃逸距离过大导致积分预算不足：60→40，远场步长放宽。
5. `capture()` 在首帧前使用默认相机 uniform：截图前强制同步相机状态。
6. 色散过强将星点拉成彩色短线：强度降至 0.0018。
7. 自动化 API `setParam` 未写入 localStorage：补 `saveSoon()`。
